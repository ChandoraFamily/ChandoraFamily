Lineage Audio Assets
=====================

You can place your own custom MP3 audio files in this folder.
The splash animations will automatically detect and play them:

1. Jai Maa Chamunda Chant:
   /sounds/jai-maa-chamunda.mp3

2. Eagle Chirp & Screech:
   /sounds/eagle-chirp.mp3

3. Sacred Fire Crackling:
   /sounds/fire-crackle.mp3

If no file is provided, the application automatically uses built-in high-fidelity Web Audio API synthesizers and devotional speech synthesis.
